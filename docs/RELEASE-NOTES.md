# Yooz - Facture Explorer 1.1.2 — Windows x64

L’application porte désormais le nom **Yooz - Facture Explorer** dans la fenêtre, l’interface, le menu À propos et l’installation Windows. L’icône sera choisie séparément.

Télécharger **Yooz-Facture-Explorer-Installation-1.1.2-x64.exe** pour installer l’application, ou **Yooz-Facture-Explorer-Portable-1.1.2-x64.exe** pour une utilisation sans installation.

Les identifiants techniques et le nom interne de l’exécutable sont conservés pour la continuité des installations et mises à jour. Correctifs de sécurité 1.1.1 conservés. Aucun mécanisme nouveau d’envoi des factures.

Exécutables non signés : avertissement Windows possible. Dépôt privé : connexion GitHub nécessaire. Mise à jour automatique réservée à la version installée avec accès local configuré. Recette visuelle Windows restant à effectuer.
