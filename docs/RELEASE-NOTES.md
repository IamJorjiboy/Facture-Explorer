# Facture Explorer 1.1.1 — Windows x64

Téléchargez **Facture-Explorer-Installation-1.1.1-x64.exe** pour installer l’application, ou **Facture-Explorer-Portable-1.1.1-x64.exe** pour l’utiliser sans installation. Les archives Source code contiennent le code, pas l’application.

Cette version comprend les fiches BT, les imports UBL/CII, le rapprochement Factur-X et les correctifs de confidentialité décrits dans docs/AUDIT-SECURITE.md : PDF.js 6.4.299, isolation des documents, restrictions réseau et durcissement Electron.

L’installateur permet les futures mises à jour ; le dépôt privé nécessite un jeton personnel de lecture configuré localement, comme expliqué dans docs/MISES-A-JOUR.md. La version portable ne s’auto-installe pas.

Les exécutables ne sont pas signés : Windows peut afficher un avertissement d’éditeur inconnu. Tests automatisés et compilation exécutés ; recette visuelle et capture réseau Windows restant à effectuer. Pas de garantie d’absence absolue de fuite ni de validation réglementaire des factures.

Les fichiers latest.yml et .blockmap servent aux mises à jour. SHA256SUMS.txt permet de vérifier l’intégrité des téléchargements. Le dépôt reste privé.
